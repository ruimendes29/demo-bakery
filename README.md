# Demo Bakery

Responsive landing page and online menu for a bakery, with a shopping cart.

**Live demo:** https://demo-bakery.vercel.app

## Features

- Sections: intro, "delicious baking", menu and "visit us"
- Shopping cart with global state (Redux)
- Responsive layout styled with SCSS

## Tech stack

React · TypeScript · Redux · SCSS · Vercel

## Running locally

```bash
npm install
npm start
```

Open http://localhost:3000.
